The 3 That Matter

What each one
actually does.

These three agents replicate workflows that used to require a full-time analyst. Here's exactly what each one does and what you get out of it.

01
EARNINGS REVIEWER
What management actually said
Paste any earnings call transcript. The agent reads it the way an analyst would — not just what was said, but what was avoided, deflected, or subtly walked back. It checks your thesis against the transcript directly.
What management committed to — with timelines
Questions they deflected or were vague on
Language tone shifts vs. prior calls
Thesis check: holds / shaken / broken
02
MEETING PREP TOOL
Intelligence before the call
Give it a stock and a date. It pulls the full intelligence brief — news since last quarter, analyst rating changes, announcements, macro context — and formats it as a pre-call brief so you walk in prepared, not reactive.
News + announcements since last earnings
Analyst rating changes and price target moves
Sector and macro context relevant to this stock
3 questions to watch for on the call
03
FINANCIAL MODEL BUILDER
Valuation in minutes, not days
Tell it the stock. Give it the latest annual report or quarterly results. It builds a working valuation model with multiple scenarios — base, bull, bear — and flags the key assumptions that drive the most uncertainty.
DCF valuation with base / bull / bear cases
Growth scenario sensitivity table
Risk breakdown ranked by impact
Key assumptions clearly stated
How to Access

Getting
started.

These agents ship as plugins in Claude Code and as cookbooks for Claude Managed Agents. Here's the fastest path to each one.

Path 01 — Claude Code (Recommended)
1
Install Claude Code
Claude Code is Anthropic's CLI tool — it runs in your terminal and lets you install agent plugins directly.
  • Install: npm install -g @anthropic-ai/claude-code
  • Sign in with your Claude account (free or Pro)
  • Run claude to launch the interactive session
2
Find the finance agent templates
Inside Claude Code, the finance agents are available as MCP server plugins. Search for "finance agents" in the plugin directory or visit the Anthropic cookbook repo for the reference architectures.
💡 The templates are pre-configured with the right domain instructions and connectors. You don't need to build the prompt from scratch — just plug in your stock and run.
3
Run your first agent — Earnings Reviewer
Start with the Earnings Reviewer. Get a transcript from screener.in (for Indian stocks) or the company's IR page. Paste it in, write your 2-sentence thesis, and let the agent run.
  • screener.in → Company → Concalls → Download transcript
  • US stocks: company IR page or SEC Edgar (EDGAR.gov)
  • The agent needs the full transcript, not the press release summary
Path 02 — Claude.ai (Simpler, slightly less powerful)
4
Use claude.ai with the right prompt structure
If you don't want to install Claude Code, you can replicate much of the same output using claude.ai directly. The free tier works for Earnings Reviewer and Meeting Prep. For the Financial Model Builder, Claude Pro (paid) gives you longer context and better numerical reasoning.

What This Means

The gap won't close
gradually.

The compounding effect of institutional research access used to mean a 5–10 year knowledge lag for retail investors. That's compressing. But access alone doesn't make you a better investor.

01
Tools don't replace thinking
An agent can read a transcript 100x faster than you. It can't tell you whether the thesis was right to begin with. The frameworks for good investing haven't changed — the speed of analysis has.
02
Speed is now table stakes
Institutional investors will also use these tools. The edge isn't access anymore — it's how quickly you learn, adapt, and build judgment. Faster learners win, not just faster computers.
03
The Excel + PowerPoint angle
The Microsoft 365 integration means these agents now run inside the tools institutions already live in. Context flows between Excel, PowerPoint, Word, and Outlook automatically — without copy-pasting.
