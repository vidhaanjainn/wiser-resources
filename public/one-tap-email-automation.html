Setup guide

Build it step by step

Three phases. One hour. Runs forever after.

01
Set up the iPhone Shortcut
iPhone · 10 mins
1.1
Open the Shortcuts app
On your iPhone, open the built-in Shortcuts app. Tap the + icon in the top right to create a new shortcut.
1.2
Add the "Ask Claude" action
In the action search bar, type "Ask Claude" — this is the official Claude action available in Shortcuts. Select it. You'll see a text field appear where you type the prompt directly into the action.
📸 This is exactly what it looks like: the shortcut shows Ask Claude followed by your prompt text in blue — e.g., "Reply to all pending mails of this week". The prompt runs inside Claude the moment you tap the shortcut. No copy-paste needed.
1.3
Write your command prompt
Inside the Ask Claude text field, type your command. Be specific — Claude reads this literally:
Reply to all pending emails of this week. // Or something more specific: Check my Gmail for unanswered emails from the last 7 days. Draft replies in my usual tone and style. Save all as drafts — do not send anything.
💡 This prompt is the trigger that connects your button to your Claude skill. Make it match whatever instruction your skill is trained to respond to.
1.4
Add shortcut to your home screen
Tap the shortcut name at the top → Add to Home Screen. Give it a name like "Email Replies" and pick an icon. Done — your button is live. One tap from now on is all it takes.
02
Connect Gmail to Claude
Claude Settings · 10 mins
2.1
Enable Gmail integration in Claude
Open Claude.ai on desktop → go to Settings → Integrations (sometimes called Connectors or Tools). Find Gmail and connect your Google account. This gives Claude the ability to read your inbox and create drafts — all via MCP (Model Context Protocol).
🔒 Claude only creates drafts — it never sends anything without you reviewing and hitting send. You stay in full control.
2.2
Test the connection
In a new Claude chat, type: "Search my Gmail for emails from the last 3 days." If it returns results from your inbox, you're live. If not, re-check the integration is turned on.
03
Design your Claude email skill
The most important part · 25 mins
What exactly is a "Claude skill"?

A Claude skill is a set of saved instructions that lives inside a Claude Project. Think of it as a trained assistant that already knows how you write, what emails to prioritize, what to skip, and how to open and close a message. Every time you run the shortcut, Claude reads these instructions first — before doing anything else. Your skill is the brain. The shortcut is just the trigger.

3.1
Create a new Claude Project
On Claude.ai, go to Projects → New Project. Name it something like "Email Assistant". This is where your skill lives. Every chat you run inside this project automatically inherits your skill instructions — so your shortcut just needs to open a new chat here.
💡 Projects have a system prompt that persists across every conversation inside them. That's your skill — set it once, and it runs every time.
3.2
Collect 5–10 real emails you've written
Go into your Gmail Sent folder and find 5 to 10 replies that represent how you actually write. Include variety: a short confirmation, a polite decline, a detailed reply, a follow-up. Copy the body of each one. These become the voice training data for your skill.
🎯 Don't describe your style in words like "professional but friendly." Show it through actual emails. Examples > adjectives, always.
3.3
Write your skill instructions
Inside your Project, open Project Instructions and paste in your skill. Here's the full structure to follow — every section matters:
Claude Project Instructions · Email Skill Template
ROLE You are my personal email assistant. // You exist inside this project for one purpose: email replies. TASK When asked to reply to pending emails: 1. Search Gmail for unanswered emails in the last 7 days 2. Skip newsletters, automated emails, no-reply senders 3. Draft a reply for each real email in my voice 4. Save all replies as DRAFTS — never send directly MY VOICE & TONE // Paste 3–5 actual emails you've written here Example 1: [paste a real reply you sent] Example 2: [paste another real reply] Example 3: [paste a polite decline you wrote] WHAT TO REPLY TO — Brand inquiries and collaboration requests — Professional questions and follow-ups — Any email from a real human that needs a response WHAT TO SKIP — Newsletters, subscriptions, automated digests — Receipts, order confirmations, bank alerts — No-reply senders — Anything older than 14 days FORMAT RULES — Match the length and energy of the incoming email — Never use stiff formal language unless they use it first — Keep replies concise — no unnecessary filler sentences — Sign off naturally, the way I do in my examples above
3.4
Test it with 3–4 real emails
Inside your Project, run the command: "Reply to all pending emails from this week." Read the drafts it creates in Gmail. Ask yourself: does this sound like me? Is the tone right? Is the length appropriate?
🔁 The first version won't be perfect — and that's completely fine. After each test run, note one thing that felt off and update your skill instructions. Two or three iterations is usually all it takes.
3.5
The full loop is now live
Tap home screen → Ask Claude fires your command → Skill runs → Gmail drafts appear. Go to Gmail, scan drafts in 2 minutes, hit send. What used to take 30 minutes of inbox chaos now takes 2 minutes of light reviewing.
⚡ Always do a final review before sending. Claude will be very close — but a 2-minute scan is what separates good automation from embarrassing automation.
Going deeper

What makes a great email skill

The output quality of your automation = the quality of your instructions.

🗣️
Voice accuracy
Show, don't describe. Adjectives like "professional but warm" are useless. Five real emails you've written are gold.
  • 5–10 real sent emails minimum
  • Include different reply types
  • Add at least one polite decline
🎯
Tight scope
Define exactly what Claude should touch and what to ignore. No scope = Claude drafting replies to newsletters.
  • Filter by sender type explicitly
  • Set a date range (7–14 days)
  • List what to skip, not just what to do
🔒
Drafts only, always
Never let automation send directly. Drafts give you a review layer that costs 2 minutes and prevents costly mistakes.
  • Explicitly say "save as draft"
  • Always review before sending
  • Add personal touch where needed
🔁
Iterate, don't perfect
Don't try to write the perfect skill on day one. Run → review → refine. It gets sharper fast.
  • 2–3 test runs is usually enough
  • Fix tone issues first, then length
  • Add edge case rules as they appear
